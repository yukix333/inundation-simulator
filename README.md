# 浸水予測シミュレーター

国土地理院の標高タイル（DEM）と降雨データを使い、ブラウザ上で浸水深を2D/3D表示するツールです。
台風や大雨の前日から数時間前に、**自分の家について「今から何をすればいいか」**を決めるための道具として作っています。

## 使い方

操作パネルは **「そなえ」「条件」「表示」** の3タブに分かれています。
「予測を実行」と判定の要約は、どのタブを見ていてもパネル下端に出ています。

1. [`inundation-simulator-v001.html`](inundation-simulator-v001.html) をブラウザで開く
2. 地図をズーム13以上にして対象地域を表示する → 表示範囲の地形データが自動で読み込まれます
3. **「そなえ」タブ →「＋ 地図から追加」を押し、地図の上で自宅などをタップする** → 名前と床の高さを入れて登録
   （ピンは後からドラッグで動かせます。名前は一覧の ✎ で変えられます）
4. **「条件」タブ**で降雨条件を選ぶ — 手動設定 ／ レーダー実況（1時間先まで） ／ **短時間予報（最大15時間先）**。
   計算方式は「簡易水位法」（即時）か「水流シミュレーション」（アニメーション）
5. パネル下端の **「予測を実行」** を押す
6. **「そなえ」タブ**の判定カードで、**予測浸水深・水が入ってくる向き・到達時刻・今からやること**を確認する

雨が降り出しそうなときは、「そなえ」タブの **「雨雲の動きを読む」** を押すと、選択中の地点について
**あと何分で降り出すか／雨雲の進む向きと速さ／速まっているか・向きを変えているか／強まっているか／
どれだけ降り続いているか**が出ます。

読み取りの手順は次のとおりです（気象庁の予報は使わず、実況だけから求めます）。

1. 直近25分ぶんの実況6枚を、地点を中心に約75km四方で読む
2. **5分きざみの区間ごと**に、まず粗い解像度で全体のずれを掴み、その周りだけを
   25個のブロックごとに調べ直して**場所ごとの流れ場**を作る
   （10分幅で一度に探すと、広い雨域では相関の山が平らになって最適解が探索範囲の端まで逃げ、
   時速100km超の誤答が出ます。5分幅なら山が立ち、区間どうしの一致も確かめられます）
3. 5つの区間を突き合わせて、**加速と向きの変化**を直線あてはめで求める
4. 地点から流れ場に沿って1分ずつ時間をさかのぼり、雨雲に当たる時刻を**到達時間**とする
5. 強さの増減は、窓を固定せず**雲を追いかけて**区間ごとに比べる
   （固定すると雲が出入りしただけで増減して見えます）

**答え合わせ付きです。** 最後の区間を伏せて流れ場を作り、1つ前の絵を動かして最新の絵を当ててみて、
雨の範囲がどれだけ一致したかを画面に出します。「動かさずに置いた場合」に勝てなかったときは、
向きを名乗らず「読み取れませんでした」と表示します。

雨雲がいまの形・速さのまま流れるという前提なので、これから新しく湧く雲は読めません。
30分より先はとくに外れやすく、目安です。先の見通しは「条件」タブのレーダー実況
（気象庁の予報）で確かめてください。

背景地図・重ねる地図・3D表示などの見た目の設定は「表示」タブにあります。
めったに触らない項目は各タブの折りたたみ（▸）の中です。見出しをクリックするとセクションごと畳めます。

登録した地点と操作値はブラウザに保存されるので、次に開いたときは同じ場所・同じ条件の続きから始められます。

**スマホでの操作:** 「操作パネル」のバーをタップすると操作部分を畳めます。バーを上下（横向きのときは左右）に
ドラッグすると、パネルの大きさを自由に変えられます。「マイ地点」などの見出しをタップすると、
そのセクションだけを畳めます。

**注意:** 現在地の取得（Geolocation API）にはHTTPSまたはlocalhostが必要です。全機能を使うには
GitHub Pages（https://yukix333.github.io/inundation-simulator/ ）から開いてください。

## 備えのための機能

- **マイ地点** — 地図をタップして自宅・職場などを登録（床の高さも一緒に）。ピンのドラッグで位置を直せます。
  ブラウザに保存され、次回もその地点から始まります
- **今からやること** — 浸水深を、地面からの深さ（通行・車）と床からの深さ（家財・垂直避難）の2軸で
  判定し、手を動かす順に並べた手順にして出します
- **到達時刻** — 降水短時間予報（最大15時間先）にもとづき、「何時ごろ道路が冠水するか」
  「車を動かせるのはいつまでか」を算出します
- **外水の想定区域** — 洪水・高潮・家屋倒壊等氾濫・浸水継続時間の公式想定区域を重ね、
  登録地点が区域内かどうかを常に照会します（内水だけを見て安心しないため）
- **水の流入方向** — 地形から水が流れ下る向きを矢印で表示し、止水板や土のうを置く面を名指しします
- **車の退避先** — 近くて高くて浸からない場所を抽出し、外水の想定区域外を優先して示します
- **共有と持ち出し** — 地点と条件を載せたリンク、文字のまとめ、電波が切れても見られるまとめ画像

## 特徴

- 単一のHTMLファイルで動作。ビルドもサーバーも不要
- マニング式による流下計算と、2D/3Dの可視化
- 窪地充填を直接解く方式による即時計算
- 水収支（水量保存）の追跡
- 画面に合わせたレイアウト。スマホでは地図が全画面になり、操作はその上に重なる開閉・サイズ可変の
  スライド式パネルで行います（畳んでも実行中・実行済みのシミュレーションは消えません）
- 気象庁の雨雲レーダー（降水ナウキャスト）・降水短時間予報との連携。地図に重ねたレーダーは
  直近15分（5分刻みで3枚）をくり返し流すので、雨雲がどちらへ動いているかが見えます。
  観測時刻と「◯分前」は地図の右上に常に出ており、新しい観測が出れば自動で切り替わります
  （リロードは不要です）
- 衛星の雲画像を重ねられます。雨雲レーダーではまだ映らない「これから来る雨のもと」が
  近づいているかを見られます。範囲は3つあります。
  - **日本周辺** — 気象庁ひまわり。直近3時間（15分刻みで13枚）の動きをくり返し流します。
    細かく（ズーム6まで）速く（2.5分ごと）更新されますが、東経90〜180度・赤道〜北緯66度の
    切り出しで、その外には何も出ません。赤外・真彩色・可視から選べます
  - **ひまわり全球** — 同じく気象庁ひまわり。直近6時間（30分刻みで13枚）。ひまわりが見ている
    半球ぜんぶ（およそ東経60度〜西経140度）が入るので、台風が生まれる熱帯や南半球まで追えます
  - **地球全体** — ひまわりは東経140.7度の静止衛星で、見えるのは中心から約81度まで。1機では
    アメリカもヨーロッパも原理的に写りません。この範囲だけは EUMETSAT の「静止衛星リング」
    （世界の静止衛星の赤外10.8μm帯を1枚に繋いだ合成）を使い、経度をひと回りぶん表示します。
    1つの製品なので継ぎ目で色が変わりません。**更新は3時間ごと**で、動きの再生と自動更新は
    しません。いま近づいている雨は上の2つで追ってください
  気象庁のタイルは観測していない範囲を塗りつぶして返してくる（赤外は白、可視・真彩色は黒）ので、
  その部分は透明にしてから重ねています。地図が塗りつぶされることはありません
  （可視・真彩色では、夜になっている範囲には何も出ません）。
  タイルの配信が粗いほうで打ち切られているため、**広域でだけ表示**し（日本周辺はズーム10以下、
  ひまわり全球は8以下、地球全体は6以下）、街区まで寄ると自動で外します（引き伸ばすと雲の形が
  読めなくなるため）。まず広域で雨雲の接近を見て、それから寄って浸水を確かめる想定です
- 登録した地点・操作値・表示位置はこの端末のブラウザにのみ保存され、外部へは送信しません

## 注意・制約

このツールが計算しているのは **内水氾濫**（降った雨が下水道の処理能力を超え、地形の窪地に
溜まる現象）の傾向のみです。次のものは **一切考慮していません**。

- **外水氾濫（河川の氾濫）** — 河川の水位・堤防・破堤による浸水は計算対象外です。河川沿いに
  浸水が表示されても、それは「その場所に降った雨」であり、川から溢れた水ではありません
- 高潮・津波
- 実際の下水道の管網配置・ポンプ場（全域一律の簡易モデルで代用しています）
- 建物（標高データに含まれないため、水は建物の上を流れます）

外水（河川・高潮）については、**計算はせず、国土地理院「重ねるハザードマップ」の想定区域を
そのまま重ねて表示するだけ**です。区域の内外は判定しますが、浸水深の区分は色分けの凡例で
読んでください。津波・土砂災害は対象外です。

「今からやること」に出る深さの数値（30 cmで車の走行が危険、など）は一般に公表されている
**目安であって、法令上の基準ではありません**。避難の判断は自治体が発表する避難情報に従ってください。

内水氾濫についても、5m標高タイルの解像度と簡易モデルによる概算です。
**実際の防災判断には、必ず自治体が公表しているハザードマップを利用してください。**
